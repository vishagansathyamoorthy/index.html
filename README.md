# CivicResolve

An AI-powered civic issue platform where citizens can report local problems
such as potholes, garbage, and water issues, and track them on a live map.

## Features
- Report civic issues with category and location
- Live map powered by Leaflet
- Offline fallback images (embedded SVGs) when the internet is unavailable
- Single-file web app, no installation needed

## Live Demo
https://vishagansathyamoorthy.github.io/Civic_resolve/

## How to Run
1. Download `Civic_response.html`
2. Open it in any modern browser

## Tech Stack
HTML, CSS, JavaScript, Leaflet.js
